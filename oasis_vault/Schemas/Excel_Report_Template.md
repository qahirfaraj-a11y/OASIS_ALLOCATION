# Excel Report Template (v9.1 Stable)
Defined structure for the output `.xlsx` files generated by `DataMixin`.

## 📊 Sheet: Order Summary
Aggregated metrics for the entire run:
- **Total Products Analyzed**
- **Total Recommended Units**
- **Total Cost (KES)**
- **Total Value (KES)** (Based on SP)
- **Estimated Savings** (10% waste reduction target)

## 📋 Sheet: Report
15-column layout for procurement teams:
1. `DESCRIPTION`
2. `BARCODE`
3. `ITEM CODE`
4. `Space` (Internal layout ID)
5. `Pack`
6. `SP` (Selling Price)
7. `Rhapta` (Current Stock)
8. `RR Prev` (Previous Recommended)
9. `RR GRN` (Days since last delivery)
10. `RR PB` (Pricing buffer status)
11. `Recommended Qty` (The final output)
12. `Historical Avg` (Anchor qty)
13. `Confidence` (HIGH/MEDIUM/LOW)
14. `Reasoning` (Full explanation)
15. `Est. Cost (KES)`
